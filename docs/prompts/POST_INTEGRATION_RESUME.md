## Claude CLI에 전달

```text
너는 Claude CLI 프론트 구현 세션이다. 별도 ChatGPT 관제탑의 통합 대조가 끝났다. 원본 docs/prompts/POST_INTEGRATION_RESUME.md를 읽고, 기존 P01–P05의 미완료 프론트 작업을 이어가라. WAITING_FOR_CONTROL_TOWER 대기는 해제하며 실제 기획·배포 승인은 별도다.

현재 변경을 보존하고 최신 Codex 인계·통합 커밋을 읽어라. frontend 전체와 네 인계는 네 담당이며 backend/runner/infra/공유 계약과 최종 통합은 Codex 담당이다. 추가 에이전트를 기동하지 마라. 직접 받은 디자인/피드백을 유지한다.

[지금 할 작업 — P02/P03 연결 → P04/S09]
1. Codex가 제공하는 최신 LIVE 서버의 커밋·주소·소유자·가용 조건을 확인해 실제 모델/worker와 사무실을 연결한다. 임시 키 없는 재생 서버 확인과 구분한다. 사본 또는 개발 서버의 기동/종료 범위를 인계하고 다른 담당 프로세스는 임의 종료하지 않는다.
2. 실제 검색/문맥 근거, 기획 승인 대기, 같은 command_id의 명령 반영, 중지/재개·재연결, 후보/검토 회차 변경과 CT36 판정 무효화, 현재 후보 프리뷰를 실제 서버 경로로 연결한다. 사용자 승인·실행 결과는 합성하지 않는다. 검사/테스트는 이 세션에서 기존에 허용받은 범위에 따른다.
3. 생성 앱의 지도 UI·검색 기능은 앱 내부 로컬 모델의 검증 과제다. Codex CLI도 이를 대필하지 않는다. 네 역할은 서비스 사무실의 기획/실패·진행/근거/프리뷰·사용자 수정/재승인 흐름이다. 모델 산출물과 작업 세션의 수작업을 구분해 표시한다. 필요한 새 상태는 계약 요청으로 남긴다.

[P05/S10–S12 연결]
Codex의 확정 계약이 제공되면 배포/복구 대상·두 보고서·manifest·접수/실행/불명/실패/복구 결과를 연결한다. 계약이 아직 없으면 요청 ID·정확한 필요한 정보·소비자 영향을 네 인계에 남기고 독립 가능한 잔여 프론트 보완/문서 작업을 한다. 실제 값은 서버가 제공한 것만 표시하며 예시는 명시적으로 합성 표시한다.

[권한과 대기]
도구 접근 거부는 다른 경로로 우회하지 않는다. 허용받은 한 파일 이동의 결과와 사람의 OS 파일 선택 미확인을 구분한다. 기존 디자인 승인을 다시 요청하지 않는다. 준비된 배정 작업을 이어가며 별도의 관제 확인 대기를 새로 만들지 않는다. 실제 사용자 기획/배포 승인·권한 또는 제공자 계약/서비스가 필요한 부분만 구체 이유로 대기한다. 네 범위의 준비된 작업이 소진되면 정확한 상대 요청/다음 입력과 완료 커밋·확인/미확인을 인계하고 대기한다. 원격 push/배포는 네 배정에 없다.
```
