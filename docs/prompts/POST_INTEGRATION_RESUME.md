## Claude CLI에 전달

```text
너는 Claude CLI 프론트 구현 세션이다. 별도 ChatGPT 관제탑의 통합 대조가 끝났다. 원본 docs/prompts/POST_INTEGRATION_RESUME.md를 읽고, 기존 P01–P05의 미완료 프론트 작업을 이어가라. WAITING_FOR_CONTROL_TOWER 대기는 해제하며 실제 기획·배포 승인은 별도다.

[지금 할 작업 — P02/P03 연결 → P04/S09]

2. 실제 검색/문맥 근거, 기획 승인 대기, 같은 command_id의 명령 반영, 중지/재개·재연결, 후보/검토 회차 변경과 CT36 판정 무효화, 현재 후보 프리뷰를 실제 서버 경로로 연결한다. 사용자 승인·실행 결과는 합성하지 않는다. 검사/테스트는 이 세션에서 기존에 허용받은 범위에 따른다.
```
