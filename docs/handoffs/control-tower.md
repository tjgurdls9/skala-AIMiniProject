# 관제탑 관찰·통합 주의사항

기록 시각: 2026-10-20 16:24 KST. 사용자 요청으로 두 구현 세션의 공개 작업 로그·인계·Git 상태를 읽기 전용으로 관찰한 기록이다. 관제탑이 직접 제품 검사나 배포를 수행한 결과가 아니다. 담당별 작업 상태는 각 worktree의 인계가 소유하며 이 문서는 주의사항만 관리한다.

## 기록 원칙 — 2026-10-21 사용자 정정 반영

- 관찰한 사건·문제·조치·결과·미확인 사항을 기록한다. 특정 활용 목적에 맞춰 사례를 고르거나 결론을 유도하지 않는다.
- 관제탑이 읽어 확인한 코드/기록, 담당자의 실행 결과 보고, 사용자의 피드백을 구분한다. 정적 관찰을 실행 재현으로, 검사 보고를 사용자 수용으로 바꾸지 않는다.
- 원인이 확인되지 않으면 추정임을 표시한다. 새 근거가 생기면 이전 기록을 지우지 않고 후속 경과로 정정한다.
- 별도 활용 아이디어나 기능 제안을 이번 관찰 기록에 덧붙이지 않는다. 담당 작업의 현재 상태는 각 담당 인계를 기준으로 한다.
