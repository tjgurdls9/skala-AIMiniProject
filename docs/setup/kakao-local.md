# 카공지도 카카오맵 로컬 테스트 준비

2026-10-21 공식 문서 확인. 사용자는 카카오맵 선택과 외부 연결 보류 해제를 지시했다. 계정의 무료 배지 확인은 아직 어렵다는 답변을 받았다. **키를 발급해도 무료 자격 확인 전에는 호출하지 않는다.** 실제 기획·배포 승인은 별도다.

## 1. 무료 자격 확인

1. [카카오디벨로퍼스 앱](https://developers.kakao.com/console/app)에서 테스트에 쓸 앱을 선택한다.
2. 해당 앱의 **[카카오맵] → [사용 설정] → [상태 ON]** 여부를 확인한다. 아직 활성화하지 않았다면 공식 안내에 따라 본인이 진행한다. 유료 설정을 요구하면 진행하지 않는다.
3. **앱 정보의 ‘카카오맵 무료 쿼터’ 배지**를 확인한다. 배지가 없으면 다른 앱이 무료 자격을 쓰는지 먼저 확인한다. 앱을 여러 개 만든다고 무료 자격이 추가되는 것은 아니다.
4. 이 테스트 앱은 **유료 API 사용 설정 비활성**을 유지한다. 과금 설정/비즈월렛 연결로 통과시키지 않는다.

2026-07-21 이후 개발자 계정에서 카카오맵을 처음 활성화한 앱에만 무료 쿼터가 제공된다. 현재 일간 무료 제공량은 Web SDK 300,000건, 키워드 검색·카테고리 검색 각각 100,000건이다. 전체 API 월간 3,000,000건 한도도 확인한다. 앱에서 실제 남은 양은 별도이며 본 코드의 카운터가 카카오 계정 전체 잔량을 알 수는 없다.

근거: [카카오맵 이용 조건](https://developers.kakao.com/docs/ko/kakaomap/common), [공식 쿼터](https://developers.kakao.com/docs/ko/getting-started/quota).

## 2. 필요한 키와 등록 주소

**같은 앱**의 [앱 → 플랫폼 키]에서 아래 두 키를 준비한다.

| 종류 | 사용 위치 | 등록/설정 |
|---|---|---|
| JavaScript 키 | 신뢰 지도 표시 화면의 Web SDK | JavaScript SDK 도메인에 **`http://localhost:8017`** 등록 |
| REST API 키 | 호스트의 신뢰 검색 어댑터 | 카카오맵 키워드/카테고리 검색 인증. 생성 코드·브라우저·모델에 전달하지 않음 |

`8017`은 **별도 신뢰 지도 화면용으로 예약한 주소**이며 아직 지도 서버가 가동된 것은 아니다. 사무실 주소 `127.0.0.1:8000`, Vite `127.0.0.1:5173`, 매번 달라지는 생성 앱 프리뷰 포트를 등록하는 방식은 사용하지 않는다. 기존 opaque 생성 앱의 sandbox를 통째로 풀지 않는다. 키 준비 뒤 신뢰 지도 화면/브로커와 프리뷰 연계를 검증해야 한다.

이번 범위는 카카오 로그인/네이티브 앱이 아니므로 리다이렉트 URI·네이티브 키·어드민 키·클라이언트 시크릿은 필요 없다. REST 키의 호출 허용 IP를 이미 제한했다면 유지하고 실제 서버의 공인 송신 IP와 맞는지 확인한다. `127.0.0.1`을 카카오가 보는 호출 IP로 등록하면 안 된다. 공유기/VPN의 공인 IP는 자동 수집하지 않았다.

근거: [앱/키 설정](https://developers.kakao.com/docs/ko/app-setting/app), [지도 Web 가이드](https://apis.map.kakao.com/web/guide/), [장소 검색 REST API](https://developers.kakao.com/docs/ko/local/dev-guide).

## 3. 로컬 저장

이미 만든 파일:

`/Users/seohyeokin/workspace/skala-AIMiniProject/.worktrees/codex-runtime/runtime-data/secrets/kakao.json`

```json
{
  "javascript_key": "",
  "rest_api_key": "",
  "free_quota_confirmed": false,
  "paid_api_disabled_confirmed": false
}
```

키 두 칸만 본인 PC에서 채운다. **무료 배지를 확인하지 못했다면 `free_quota_confirmed`는 false를 유지한다.** 마지막 확인값도 실제 유료 API 비활성을 확인한 뒤에만 true로 바꾼다. 키 값은 채팅·Git·인계·스크린샷에 넣지 않는다. JavaScript 키는 SDK 로드 시 브라우저에서 보이는 값이므로 등록 도메인 제한이 필요하다.

파일은 현재 사용자 소유·권한 `600`이어야 한다. 편집기가 권한을 바꿨다면 아래 명령으로 복구한다.

```sh
chmod 600 /Users/seohyeokin/workspace/skala-AIMiniProject/.worktrees/codex-runtime/runtime-data/secrets/kakao.json
```

`runtime-data/`는 Git 제외이며 기존 파일을 덮어쓰지 않고 빈 틀만 생성했다. 키를 준비하면 “로컬 파일 준비 완료, 무료 배지 확인 여부”만 알려준다. 준비 사실은 기획/배포 승인이 아니다.

## 4. 키 없이 완료한 범위와 남은 조건

`backend/kakao.py`는 비공개 키 로드·명시 동의·고정 Kakao HTTPS 목적지·CE7 카페 검색·응답 제한·오류 비공개·로컬 일 200회 시도 한도와 429 후 당일 중단을 구현한 **미연결 어댑터**다. 실제 네트워크 없이 합성 키/MockTransport로 검사한다. 좌표·검색어·응답은 DB에 저장하지 않고 날짜/횟수/차단 여부만 저장한다. 재시작해도 시도 수를 유지하고 자동 재시도/유료 전환을 하지 않는다.

카카오 장소 API만으로 조용함·콘센트·Wi-Fi·장시간 체류 적합성은 확인되지 않는다. 거리/키워드 기준의 카페 발견과 공부 적합성 보증을 구분하며 정보를 만들지 않는다.

무료 배지·키·정확한 도메인 확인 → 신뢰 지도/브로커의 격리·동의 검증 → 새 실제 기획 검토/사람 승인 → 런타임 생성 앱·독립 검토·프리뷰 수용 순서가 남는다. 현재는 실제 카카오 요청·GPS 권한 요청·앱 구현 승인·배포를 하지 않았다.
