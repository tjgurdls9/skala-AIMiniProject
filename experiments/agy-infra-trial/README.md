# agy 샌드박스 시험 패키지

과제: AGY-TRIAL-001 · 상태: 첫 응답 검토 완료, 수정 필요. [관제탑 검토](../../docs/reviews/AGY-TRIAL-001-review.md)에 근거와 후속 요청이 있다.

본 프로젝트의 Infra 소유권은 아직 Codex CLI에 있다. agy에는 합성 설정의 검토·수정안 제안만 시험한다. 이 세션은 관제탑으로 결과를 평가하고 통합 여부를 결정한다. 실제 배포·자격증명·클라우드 자원을 주지 않는다.

## 시작 위치

실제 실행은 이 소스 패키지 안이 아니라 `/private/tmp/`에 만든 별도 복사본의 `workspace/`에서 한다. 복사 대상은 TASK.md와 input의 합성 파일뿐이다. 실제 소스·PDF·.git·.env·키·모델은 복사하지 않는다. 현재 생성된 경로는 [준비 기록](../../docs/planning/agy-trial.md)에 있다.

폴더 분리 자체를 보안 샌드박스라고 부르지 않는다. 설치된 CLI의 `--sandbox`를 함께 사용하고 `/config`에서 sandbox·작업 영역 밖 접근·권한·무료 사용 조건을 확인한다. 초기에는 `--mode plan`으로 보고서와 수정안을 먼저 받는다. plan은 작업 방식이며 OS 격리의 대체물이 아니다. [공식 CLI 모드](https://www.antigravity.google/docs/cli/modes/), [공식 샌드박스](https://www.antigravity.google/docs/sandbox/)

## 실행 전 확인

- CLI는 현재 복사본만 작업 폴더로 사용한다. 실제 프로젝트를 `--add-dir`로 추가하거나 기존 제품 세션을 이어가지 않는다.
- `--sandbox` 적용 상태를 확인한다. sandbox 밖 실행·추가 폴더·웹·MCP·명령 실행·비밀 접근 요청은 이 과제에서 승인하지 않는다.
- 이번 단계는 파일 읽기와 답변만 필요하다. 수정안을 파일로 저장할 때도 검토 뒤 `output/`에 한정해 허용한다. 전역 권한·기존 계정 설정은 준비 과정에서 변경하지 않았다.
- 무료/포함 사용량과 모델 접근을 사용자 계정에서 확인하고, 유료 AI credit 추가 사용(`Use AI Credits`)은 끈다. 무료 자격/자동 과금 차단을 확인할 수 없으면 모델 호출을 시작하지 않는다. 특정 유료 모델·새 API 키를 이 패키지에서 설정하지 않는다.
- Docker 데몬은 준비 시점에 연결되지 않았다. 이는 native CLI sandbox와 별개다. 빌드·실행·배포를 수행했다고 보고하지 않는다.

## 전달할 문장

```text
TASK.md를 읽고 AGY-TRIAL-001을 수행해줘. input의 합성 설정만 검토하고 보고서와 수정 설정을 답변 코드 블록으로 먼저 제시해줘. 파일 변경·명령 실행·외부 접근·추가 에이전트 기동은 하지 마. 확인하지 못한 항목은 미확인으로 표시해줘.
```

CLI 호출은 준비 기록의 실제 경로를 사용한다. `--sandbox --mode plan`을 유지하고 bypass/auto-approve 옵션을 추가하지 않는다. 첫 수정안 검토 후 output 파일 작성 여부를 결정한다. 관제탑이 실제 차이와 결과를 확인하기 전에는 본 저장소에 병합하지 않는다.

## 종료·회수

Ctrl+C로 종료할 수 있다. 답변·output·실행 여부만 관제탑에 전달한다. 임시 경로는 시스템이 정리할 수 있으므로 유효한 결과는 secret이 없는지 확인한 뒤 보관한다. 홈이나 실제 저장소의 접근을 시험하기 위해 실제 비밀 파일을 읽는 행동은 하지 않는다.
